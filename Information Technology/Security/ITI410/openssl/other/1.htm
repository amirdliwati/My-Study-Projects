رد: OpenSSL!!!!!
The assignment aims at enforcing the cryptography techniques. It helps the student in acquiring the necessary knowledge in understanding cryptography applications and in securing data using encryption techniques.
Objectives can be summarized as:
· Understanding cryptography applications
· Encrypting and decrypting using DES and RSA
· Hashing using SHA1
Assignment Details


Purpose

The purpose is to master OpenSSL, an open source toolkit providing general purpose cryptography features. It aims at mastering the following issues:
  • Creating secret keys
  • Creating Private/Public keys
  • Encrypting using symmetric cryptography algorithms.
  • Encrypting using asymmetric cryptography algorithms.
  • Hashing content
  • Signing content

Functionalities
  • Create a Word document called “MyGroup.doc” containing the following information:
    • Full name, ID and class of each one of the group members
    • The sentence "My hopes are not always realized, but I always hope."
  • Choose a password from 8 to 12 letters that will be used by OpenSSL to create your secret keys for some of the following questions. Save this password in a file called "MySecretKey.txt".
  • Write a command line in a batch file called "Encrypt_DES.bat" to encrypt the content of the data file “MyGroup.doc” using DES Encryption algorithm and the key saved in "MySecretKey.txt". Run the command and save the encrypted file as "DataFile_DESEncrypted.txt".
  • Write a command line in a batch file called "Decrypt_DES.bat" to decrypt the content of the file "DataFile_DESEncrypted.txt" and generate an output file called "DataFile_DESDecrypted.doc". Run the batch file and compare "MyGroup.doc" with "DataFile_DESDecrypted.doc".
  • Write a command line in a batch file called "Encrypt_DES3.bat" to encrypt the content of the data file “MyGroup.doc” using DES3 encryption algorithm and the key in "MySecretKey.txt". Run the command and save the encrypted file as "DataFile_DES3Encrypted.txt".
  • Write a command line in a batch file called "Decrypt_DES3.bat" to decrypt the content of the file "DataFile_DES3Encrypted.txt" and generate an output file called "DataFile_DES3Decrypted.doc". Run the batch file and compare "MyGroup.doc" with "Datafile_DES3Decrypted.doc".
  • Write a command line in a batch file called "Encrypt_AES.bat" to encrypt the content of the data files “MyGroup.doc” using AES 256 bits encryption algorithm and the key in "MySecretKey.txt". Run the command and save the encrypted file as "DataFile_AESEncrypted.txt".
  • Write a command line in a batch file called "Decrypt_AES.bat" to decrypt the content of the file "DataFile_AESEncrypted.txt" and generate an output file called ‘DataFile_AESDecrypted.doc". Run the batch file and compare "MyGroup.doc" with "DataFile_AESDecrypted.doc".
  • Write a WORD document called "DES_DES3_AES_Comparison.doc". Write down in the document the comparison between the speeds of the three algorithms.
  • Write a command line in a batch file called "Hash_SHA1.bat" to hash the file "MyGroup.doc" using SHA1 algorithm. Run the command and save the generated hash string to a file called "DataFile_SHA1Hash.txt".
  • Write a command line in a batch file called "Hash_MD5.bat" to hash the file "MyGroup.doc" using MD5 algorithm. Run the command and save the generated hash string to a file called "DataFile_MD5Hash.txt".
  • Write a command line in a batch file called "Hash_ RIPEMD160.bat" to hash the file "MyGroup.doc" using RIPEMD160 algorithm. Run the command and save the generated hash string to a file called "DataFile_ RIPEMD160Hash.txt".
  • Write a WORD document called "SHA1_MD5_ RIPEMD160_Comparison.doc". Write down in the document the comparison between the hash string lengths of the three algorithms.

  • Write a command line in a batch file called "Generate_RSAKeys.bat" to generate RSA private/public keys of 2048 bits length in an output file called "RSAKeys.pem". Run the command Generate_RSAKeys.bat".

  • Write a command line in a batch file called name "Extract_RSAPublic.bat" to extract the RSA public key to a file named "RSA_PublicKey..pem".
  • Write a command line in a batch file called "Encrypt_ RSA_Public.bat" to encrypt the file "MyGroup.doc" using RSA public key. Run the command and save the encrypted data to a file named "Encrypted_ RSA_Public.txt".
  • Write a command line in a batch file called "Decrypt_ RSA_Private.bat" to decrypt the file "Encrypted_RSA_Public.txt" using RSA private key and save the decrypted data to a file called "Decrypted_RSA_Public.txt".
  • Write a command line in a batch file called "Sign_RSA.bat" to sign the file "MyGroup.doc" using RSA algorithm. Run the command and save the signature to a file named "RSA_Signature.txt".
  • Write a command line in a batch file called "Check_Sign_RSA.bat" to verify the signature "RSA_Signature.txt" of the file "MyGroup.doc" using RSA algorithm.

  • You have to share your secret keys and your RSA private key with your tutor. Write a batch file called "RSAEncrypt_MySecretData.bat" to encrypt "MySecretKey.txt" and "RSAKeys.pem" using the tutor public key "Tutor_RSAPublicKey.pem" and generate the output files "MySecretKey_Encrypted.txt" and "RSAKeys_Encrypted.txt". The tutor public key "Tutor_RSAPublicKey.pem" is included in the assignment package.

des- : هي طريقة التشفير .. طبعاً في عدّة Modes منها cbc و ال cfb و الofb ( بيصير الشكل : des-cbc- إلخ ).. لما كتبناها متل ما هي بدون إضافة ال Mode بالمثال .. فهاد يعني إنو رح ياخد ال mode الافتراضي اللي هو ال cbc
in- : بعدها منكتب مسار الملف اللي بدنا نشفرو
out- : بعدها منكتب المسار اللي بدنا نحفظ فيه الملف الناتج ومنحدد فيه اسم الملف الناتج
pass- : مشان إدخال كلمة السر .. لاحظتو إني ضفت :file و بعدها فوراً مسار الملف الموجودة فيه كلمة السر .. في حال ما ضفتو ال :file رح يصير إدخال كلمة السر ضمن نافذة ال cmd ..

كود:
enc -des -d -in C:\Project\DataFile_DESEncrypted.txt -out C:\project\DataFile_DESDecrypted.doc -pass file:C:\Project\MySecretKey.txt
