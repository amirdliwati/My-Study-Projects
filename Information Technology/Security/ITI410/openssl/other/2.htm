openssl
تحياتي شباب وصبايا

عندي وظيفة ITI410 Data Security

وهي عن استخدام برنامج ال OpenSSL

فبدي استعين بخبرتكون بكم سؤال ومنو منتناقش على حلول الوظيفة وبيستفيد منها إلي عندو ياها

سؤالي أنا

عندي باسوورد مشفر ناتج عن هالطلب
17. Write a command line in a batch file called "Encrypt_pwd.bat" to encrypt the password stored in "pwd.txt" using the public key of the client "C2" (his/her certificate). Use the command "smime" for this purpose. Run the command and save the result in a file called "pwd.enc".

وهو صار بملف pwd.enc

في الطلب إلي عم استفسر عنو أنو بدو يانا الدكتور انو انفك تشفير هالباسوورد
بس باستعمال تعليمة smime
وهادا نص الطلب
20. Write a command line in a batch file called "Decrypt_Pwd.bat" to decrypt the encrypted password "pwd.enc" using the private key of client “C2”. Use the command "smime" for this purpose. Run the command and save the result in a file called "pwd_dec.txt".

طيب استفساري انو فك شيفرة هالملف هيي متلها متل فك شيفرة الرسالة المشفرة

يعني كود فك شيفرة الرسالة المشفرة كالتالي
openssl smime -decrypt -in message.enc -inkey.pem -out message.txt

هل هو نفسو على ملف الباسوورد ؟
يعني بيجوز هيك ؟

openssl smime -decrypt -in pwd.enc -inkey.pem -out pwd.txt

؟؟

يا ريت لو اتفيدوني يا شباب
